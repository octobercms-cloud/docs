# Organizations

Organizations let teams collaborate on October Cloud applications under a shared account. Use an organization when multiple people need access to the same applications, such as developers, designers, or agency clients.

## Owners

Every organization has exactly one owner. The owner is the account that created the organization and is responsible for billing and membership.

The owner has full access to all organization applications and can perform actions that are restricted to them alone. See [Permissions](#permissions) below.

## Members

Organizations can have any number of members. Members are invited by the owner and gain access to all applications within the organization.

Once added, a member can work with organization applications the same way the owner can for day-to-day operations—there is no per-application access control within an organization.

## Permissions

Members have full privileges within an organization's applications. This includes:

- Triggering deployments
- Managing domains
- Editing environment variables
- Viewing logs
- Running commands
- Configuring databases, storage, and other application resources

The following actions are restricted to the organization owner:

- Inviting new members
- Deleting an application

All other application management tasks can be performed by any member.
