# Databases

Every application provisions a Serverless Postgres 18 database powered by [Neon](https://neon.tech).

## Manual Connection

In "Settings", you'll find a deep-link sign-on button for your database. Clicking it opens a connection deep link that compatible clients—such as [TablePlus](https://tableplus.com)—can use to connect with your credentials already filled in, so you don't have to copy host, user, and password by hand.

## Monitoring

Settings also includes monitoring tools for disk space, CPU usage, and memory usage.

## Backups

Automated backups are included by default, with daily snapshots retained for 7 days.
