# Welcome to October Cloud

The official hosting platform for [October CMS](https://octobercms.com). Let us worry about infrastructure; you just focus on what makes your website amazing.

October Cloud is a fully managed hosting and deployment platform. Here are just some of the features included,

- Databases
- Object storage
- SSL certificates
- Push to deploy
- Any much, much more!

## Project Status

We're currently in a private beta. There may be rough edges while we work towards general availability. If you encounter a problem, please contact [support@octobercms.cloud](mailto:support@octobercms.cloud), or open a thread [here on reddit](https://www.reddit.com/r/octobercms/).

If you'd like to participate in beta, please [join the waitlist](https://octobercms.cloud)!
