# Welcome to October Cloud

The official hosting platform for [October CMS](https://octobercms.com). Let us worry about infrastructure, and you just focus on making your website amazing.

## Mission Statement

Operating servers or using shared hosting can be a logistical and security nightmare. We're here to help. Let us handle complexities like:

- Integrating workflows between developers, designers, and content teams
- Database provisioning and backups
- Custom domains and SSL certificates
- Push-to-deploy with zero downtime
- Object storage and content delivery networks
- Security updates

We'll provide everything you need for a world-class experience with October CMS.

## Dedicated Resources

Unlike shared hosting, our platform creates dedicated resources that are yours, and yours alone. Say goodbye to "noisy neighbor" problems for good.

- Web server
- Database
- Object storage
- Caches
- Queue workers

Everything belongs to you.
